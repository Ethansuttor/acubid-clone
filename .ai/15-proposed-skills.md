Updated September 7, 2026. The filename is historical: these seven skills
already exist under .claude/skills/. They are not pending approval.

| Skill | Use for | Current scope |
| --- | --- | --- |
| estimating-math | Quantity, extensions, commercial calculations, parsers | Independent expected values, shared pure logic, explicit policy |
| ai-feature | Local detection or optional provider changes | Pending review, bounded input, key isolation, evidence distinctions |

| job-cost-math | Explicitly assigned post-award work | Deferred domain guidance; validate policies before use |

User instructions control scope. These files should help execution, not force
unrequested account setup, blanket approvals, or implementation of future
backends. Routine reversible work proceeds within the existing authorization.

The skills were reconciled with
[18-parallel-execution-plan.md](18-parallel-execution-plan.md). They distinguish
implemented behavior from proposed desktop/cloud capabilities. Read only the
skill relevant to the task; do not load every future domain rule.

When updating guidance, preserve non-obvious correctness requirements and
remove stale counts, inaccurate environment assumptions, repeated queues, and
absolute claims unsupported by tests. Keep detailed task steps in the packets.
