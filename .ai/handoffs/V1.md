## Raster comparison: regenerated (this checkout) vs recorded (`/home/user/acubid-clone/eval-out`)

Legacy pypdfium2 rasters only; the recorded ones were made on another machine, apparently Windows (their manifests carry backslash paths).

- Manifest content (scale, canvas size, template size and page box, all tile boxes and counts) is identical for all four
  fixtures apart from the `pdf` path separator.
- Template rasters are byte-identical for troffer, duplex and exit. The switch template differs: the switch symbol is a
  Helvetica-Bold "S" text glyph, so its outline depends on the platform's font handling.
- Full-canvas pixels differing: troffer 0.48% (48,605 of 10,077,696), duplex 0.27% (128,260 of 47,979,848),
  switch 0.21% (151,064 of 71,663,616), exit 0.29% (118,276 of 40,310,784). Most differences are small gray-level changes
  (for troffer, 6,288 pixels differ by 32 levels or more and 491 by 128 or more); a one-pixel shift makes the difference larger,
  so this is antialiasing/glyph rendering, not misalignment.
- Inside the labeled symbol boxes: duplex 0 of 92,272 pixels differ; exit 0 of 10,804; troffer 1,143 of 299,750 (0.38%, at most 130
  levels); switch 3,456 of 38,025 (9.1%, at most 203 levels, the glyph).
- Detection results still reproduce exactly (above), so the raster differences are treated as acceptable. Not investigated further
  (the wrap-up request came first): which pdfium build produced the recorded rasters.

Renderer equivalence for `eval:detection` (tests in `tests/eval-render.test.ts`): SymbolSearch's scale, canvas-size, template-crop
and mapping lines are pinned by a source-text test, both offline renderers map PDF points to top-left pixels like the manifests do
(checked on a marker PDF), and production `cropCanvas` copies the template pixels exactly on the harness canvas. Differences the tests
cannot remove: Skia vs Chromium antialiasing; pdf.js loads its bundled standard-font data in Node while the browser substitutes a system font.
Also note the app-faithful scale differs from the legacy scale (32-megapixel cap: 2.67 versus 3.27/4/3 for duplex/switch/exit).
