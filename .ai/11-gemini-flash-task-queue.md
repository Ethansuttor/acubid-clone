These tasks touch shared components/configuration. Do not dispatch them to edit
Summary, Database, root scripts, or documentation concurrently with D/S/A/V
owners. Reserve paths or defer until integration finishes.

Use the worker preamble and handoff template from the active queue. Required
dependencies and reversible implementation steps are normal authorized work;
there is no blanket ban on packages or an extra owner-only review ceremony.
High-impact money/storage changes need appropriate evidence and coordination,
regardless of the model that implements them.
